# Original audio foundation

All 29 mono PCM WAVs are original project synthesis, generated by `tools/audio_pipeline/generate_audio.py` using only Python's standard library. There are no sampled recordings, reference-image assets, third-party audio, voice performances or external sound libraries. The project may modify and redistribute these original assets with its game. The generator is the editable source; `manifest.json` records parameters, duration, category and SHA-256 identity for every export.

Run `python tools/audio_pipeline/generate_audio.py` from the project root to regenerate the files deliberately. Output is deterministic at 22,050 Hz, signed 16-bit, mono. Fixed SHA-derived local seeds do not use gameplay randomness. Godot uses the pre-generated WAVs; Python is unnecessary at runtime.

The six `_loop.wav` resources have forward looping enabled in their tracked Godot `.wav.import` sidecars (`edit/loop_mode=2`). Regeneration preserves this setting when sidecars exist; on a new library, import first and enable forward looping for `_loop` files. Track WAVs, manifest and import sidecars; `.godot/imported/` remains ignored.

Families: two variants each for player, Raider and ground-guard discharge; six explicit impact surfaces; actor damage/destruction; three machine loops; three environment loops; five interface confirmations; one flare signal. Raider damage is a restrained synthetic gear/body cue rather than a human vocal performance. Spatial attenuation and category gain belong to the presentation profiles, players and bus layout rather than the samples.

Use the actor inspection scene for shared discharge, impact, damage, destruction and motor auditions. Listening balance, realism, loudness and positional readability require director review on speakers/headphones. No soundtrack is supplied.
