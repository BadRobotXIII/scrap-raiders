# Stage Y delivery evidence

Captured 2026-10-25 with Godot 4.7.2 Standard / Forward+ and Blender 4.5.10 LTS. See the [delivery report](../../reports/stage_y_world_population.md) for scope, interpretation, caveats and the director checklist. Checkpoint Y awaits manual acceptance.

- `regression/validation.json` and verbose suite logs: editor plus all forty active suites, completion markers and exits. `cleanup_classification.json` identifies the retained accelerated WAV-only shutdown reports; native Y and graphical logs are separate.
- `accepted_environment_manifest.json`: byte-preserved eight-asset manifest, authenticated by the historical V hash. `sources_before.json`, `source_comparison.json` and `reviewed_sources.json` preserve pre-Y identities, the eleven baseline-file changes (including the test index) and final source inventory. Prior uncommitted work was not discarded.
- `roundtrip.json` and `reimport_*.json`: protected pilot source-edit/export/reimport/restoration fingerprints and shared bindings.
- `replay_comparison.json`, three replay JSONs and `replay_validation.json`: protected X versus Y west/east runs plus a Y repeat. Each observes forty seconds; the west window has no shots, east has nineteen. Raw snapshots include physical navigation/targets/shot endpoints/transfers/objectives/stash.
- `full_inventory_Windows.json`: both layout inventories, colliders, stock clearance, materials, source-batch instances, signs and physical contract.
- `performance/`: matched final bay/overview, pilot and seven-shot/eight-death measurements. Rejected first/second geometry trials are retained and identified; they are not final delivery results. Accepted-X before data/captures remain in the [planning audit](../stage_y_environment_audit/README.md).
- `screenshots/`: final both-layout/all-zone captures, sixteen-asset inspection, pilot and expanded recovery/results/post-death views. The original before-images remain in the planning audit.
- `graphical_validation.json`, `full_graphical.log.txt`, native/accelerated Y logs, `clean_validation.json` and clean import/runtime logs: actual graphical workflow and isolated runtime validation without Blender sources.
- `probes/`: authoring and QA scripts saved as `.txt` so Godot does not import them as production code. They used ignored `.godot/` saves/outputs and are evidence, not runtime dependencies. Paths inside them describe the validation workspace and may need adjustment for replay.

The global renderer texture-memory increase is reported without resource-level attribution; no additional environment maps were authored. Recorded timing and frame statistics describe this local machine and bounded fixtures. Screenshots and automated fixtures do not replace director play-testing. The roof-support amendment remains excluded; no commit/publication is part of this delivery.
