# Stage U validation evidence — 2026-10-21

See the [delivery report](../../reports/stage_u_world_expansion.md). This archive is inside the existing ignored-by-Godot development baseline tree; runnable probes and isolated saves stayed under Git-ignored `.godot/stage_u/`. No real player stash was used.

- `source_manifest.json`: SHA-256 identities for 232 delivered script, UID, scene, resource and project files. `source_changes.json` compares against accepted T: two existing files changed and eleven new runtime/test files were added. All other accepted gameplay source identities match.
- `before/`: fresh editor/import and all 31 accepted suites at ordinary engine timing, before project edits. The legacy extraction suite reported the existing two-instance ObjectDB cleanup warning.
- `ordinary/`: full post-change editor/import and all 32 suites at ordinary timing. All pass; the same legacy extraction cleanup warning recurred. U tests were subsequently extended; final focused runs listed below cover the complete delivered test source.
- `accelerated_validation.json`: complete fixed-60-FPS run, all 32 passing. Accelerated audio cleanup warnings are not treated as ordinary runtime failures. `accelerated_audio_verbose.log.txt` identifies WAV stream/playback references in a diagnostic run.
- `validation.json`: consolidated completion register. `u_final_graphical.log.txt` is the complete final U suite under Forward+ at ordinary timing, including physical alternate retreat, social reporting/betrayal, cargo banking/forfeiture and replay. `expanded_world_test.log.txt` is its final headless fixed-step run. Final focused logs contain no errors/warnings; `final_log_issues.json` records the scan. Full ordinary-suite warnings remain separately visible in `ordinary/`.
- `final_editor.log.txt`, `headless_startup.log.txt`, `graphical_startup.log.txt`: final parsing/import and bounded scene launches. Startup is briefing-gated; natural observations and tests separately exercise deployed simulation.
- `gui.log.txt`, `compact_graphical_flow.log.txt`: actual graphical Deploy interaction, player firing/recovery, recall/results and compact GUI/routing regression. `briefing.png`, `active.png`, `success.png` are the final U GUI captures; active and overview images were visually inspected.
- `compact_87017.json` through `compact_87021.json`: five matched compact deployments. First two were collected before edits, last three after the config/Overlay seam; accepted AI/resources and compact geometry are unchanged.
- `u_87017.json` through `u_87021.json`, `u_repeat_87018.json`: five natural expanded deployments plus a repeat, at normal simulation speed. No teleport, cargo grant, forced relation, kill or scheduler override. Observers run concurrently, so these are not wall-clock performance measurements.
- `natural_summary.json`: derived pacing/accounting observations; first shot is global, not time-to-player-contact. Shot gaps exclude the tails before the first/after the last shot. Combat seconds are per-actor episode sums and may overlap. Every run preserves conservation, bounds and immutable settled player results.
- `performance_compact.json`, `performance_expanded.json` and matching logs: sequential 30-second Forward+ measurements after concurrent checks ended. Both use identical overview camera, 1600×900, no optional metrics and an explicitly arranged early admission of all five initial IDs. Actors still act, die and extract independently. The JSON records actual five-Raider/two-machine frame counts; this population is not held fixed artificially for 30 seconds.
- `overview_compact.png`, `overview_expanded.png`: paired camera views. `observe.gd.txt`, `gui.gd.txt`, `performance.gd.txt` preserve exact development probes as non-executable text. Performance records load-to-ready, separate repeated bake/map synchronization, engine monitors, frame intervals and static memory. These are local measurements, not exclusive CPU/GPU profiles or export certification.

The original ordinary full-suite U run and focused final U extensions are deliberately distinguished; prior suites were not weakened. Source gameplay, seed setup and event outcomes are not inferred solely from suite names or exit codes. No Stage U acceptance, Stage V or Git publication is claimed.
